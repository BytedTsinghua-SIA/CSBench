# Assignment 2: Fun with Collections

## Background
This assignment builds experience with collections by implementing a trigram-based language identifier and a flood-fill simulation over a terrain grid.

## Core Tasks
- RosettaStone.cpp: implement kGramsIn, normalize, topKGramsIn, cosineSimilarityOf, and guessLanguageOf to build and compare k-gram profiles.
- RisingTides.cpp: implement floodedRegionsIn to compute flooded cells from water sources using a queue-based search over the terrain.
- LanguageIdentification.txt: run the Rosetta Stone demo

## Scoring (1-3 points)
1. Rosetta Stone functions produce correct k-gram counts, normalization, and similarity-based language guesses.
2. Rising Tides correctly floods reachable cells without diagonal flow and handles multiple sources efficiently.
3. Written responses in LanguageIdentification.txt and consistent with program output.
