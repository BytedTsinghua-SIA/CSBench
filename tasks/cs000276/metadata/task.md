# Assignment 3: Recursion

## Background
This assignment practices recursive problem solving through fractal drawing, memoization, combinatorial generation, and backtracking optimization.

## Core Tasks
- Sierpinski.cpp: implement drawSierpinskiTriangle to render the recursive triangle and report an error for negative order.
- HumanPyramids.cpp: implement weightOnBackOf with memoization and input validation.
- WhatAreYouDoing.cpp: implement allEmphasesOf using tokenize to generate all capitalization variants of words while preserving non-words.
- ShiftScheduling.cpp: implement highestValueScheduleFor to choose a maximum-value, non-overlapping schedule within hour limits.

## Scoring (1-3 points)
1. Sierpinski and Human Pyramids produce correct results and handle invalid inputs efficiently.
2. What Are You Doing generates exactly all valid emphases without duplicates and handles punctuation correctly.
3. Shift Scheduling returns an optimal schedule under constraints.
