# Advanced React Patterns (Part 7)

## Background
You are extending the anecdotes and bloglist applications with routing, custom hooks, and advanced state management patterns. The work emphasizes reusable logic for navigation, notifications, hooks, and state transitions that mirror a production React app.

## Core Tasks
1. Routing and notifications for anecdotes:
   - Define routes for list, create, and detail views.
   - Show a five-second notification after creating an anecdote.
2. Custom hooks:
   - Implement a field hook with reset and safe input props.
   - Build a country hook that maps API responses and controls when to fetch.
   - Build a reusable resource hook for fetching and creating resources.
3. Bloglist extensions:
   - Add Prettier configuration.
   - Provide Redux reducers/actions or Context/Query equivalents for notifications, blogs, and user sessions.
   - Implement views for users and blogs, navigation, and blog comments.
   - Provide a styling theme selector for basic UI customization.

## Scoring Points (1–3)
- Correct routing, notification timing, and hook behavior.
- State updates for bloglist (create, like, delete, session) are modeled accurately.
- Views, comments, navigation, and formatting/styling helpers are complete and consistent.
