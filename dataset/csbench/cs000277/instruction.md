# Assignment 4: Recursion to the Rescue

## Background
This assignment deepens recursive problem solving with debugging, backtracking, and search over graphs and constraints.

## Core Tasks
- Permutations.cpp: diagnose and fix the permutation bug using the debugger, then answer the required questions in DebuggingAnswers.txt.
- TowersOfHanoi.cpp: implement the recursive solver and produce the correct move count.
- Matchmaker.cpp: implement perfect matching and maximum-weight matching for an undirected weighted graph of people.
- DisasterPlanning.cpp: implement disaster supply placement with backtracking and correct output sets.

## Scoring (1-3 points)
1. Permutations and Towers of Hanoi behave correctly and DebuggingAnswers.txt is complete.
2. Matchmaker functions return correct matchings and handle edge cases efficiently.
3. Disaster Planning returns valid minimal supply placements.
