# React Native Repository App (Part 10)

## Background
You are building a React Native application for browsing and reviewing GitHub repositories. The app includes repository lists, authentication flows, review creation, and user-specific views backed by a GraphQL API.

## Core Tasks
1. UI foundation and forms:
   - Implement repository list items, app bar tabs, routes, and platform-specific typography.
   - Build sign-in and sign-up forms with validation and error states.
2. Data access and authentication:
   - Fetch repositories with GraphQL queries, ordering, filtering, and pagination.
   - Implement sign-in mutation handling, token storage, and sign-out behavior.
3. Repository and review features:
   - Build single repository views with review lists and actions.
   - Add review creation, user review listing, and review actions (view/delete).

## Scoring Points (1-3)
- Correct formatting, routing, and form validation across the UI helpers.
- GraphQL query variable handling, auth token storage, and sign-out behavior work as specified.
- Review list rendering, review actions, and pagination logic are consistent.
