# Background

要求实现**自定义模拟场景**并探索参数对仿真结果的影响。

# Task Description

你需要完成并展示至少以下能力：

1. **使用 `add_object` / `add_circle` / `add_rect` 等方式构建不同模拟场景**

   - 可自由调整：粒子数、形状、初始位置、初始速度等。

2. **探究材料参数对模拟结果的影响（至少包含杨氏模量 \(E\)）**

   - 例如：同一场景内放置两团雪，分别设置不同 \(E\)，对比形变程度/“弹性”表现，并结合物理原理解释原因。

3. **改变物理模型或算法实现新的模拟结果**
   - 示例：水（fluid）冲击弹性体（jelly）的两相耦合模拟；或喷泉等持续注入场景。
