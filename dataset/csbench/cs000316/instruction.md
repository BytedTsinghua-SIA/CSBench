# CS 161 Summer 2023 - Project 1: Exploiting Memory Safety Vulnerabilities

## Project Overview

This project focuses on exploiting memory safety vulnerabilities in a series of vulnerable programs running on a virtual machine. Students work individually or in teams of up to 2 members to demonstrate understanding of common memory safety issues and exploitation techniques.

## Story Background

The project is set in a space exploration context where you are part of the Caltopia Space Agency's Jupiter exploration program. The mission requires deorbiting old, insecure satellites left by the former Gobian Union. As these satellites use outdated, vulnerable technology, your task is to hack into them and safely remove them from orbit to clear the path for Jupiter-bound spacecraft.

## Core Tasks

You will exploit seven vulnerable satellite control programs, each representing a different memory safety vulnerability:

1. **Question 1: Remus** - Basic buffer overflow exploitation
2. **Question 2: Spica** - Format string vulnerability
3. **Question 3: Polaris** - Stack-based buffer overflow with protections
4. **Question 4: Vega** - Heap-based vulnerability
5. **Question 5: Deneb** - Use-after-free vulnerability
6. **Question 6: Antares** - Race condition exploitation
7. **Question 7: Rigel** - Advanced exploitation challenge

## Requirements

- Work on a provided virtual machine environment
- Successfully exploit each vulnerable program to gain control
- Demonstrate understanding of the underlying vulnerabilities
- Submit working exploits that achieve the specified objectives
- Team size: 1-2 students

## Learning Objectives

- Understand common memory safety vulnerabilities (buffer overflows, format strings, heap corruption, etc.)
- Learn exploitation techniques and mitigation bypasses
- Gain practical experience with debugging and reverse engineering
- Apply security concepts in a controlled environment
